# ADR-NNN: título da decisão

| Campo | Valor |
|---|---|
| Status | proposta / aceita / substituída por ADR-NNN |
| Data | AAAA-MM-DD |

## Contexto

A situação que forçou a decisão. Restrições reais: prazo, time, infraestrutura, integração existente.

## Decisão

O que foi decidido, em uma frase no presente. "Usamos X para Y."

## Alternativas consideradas

| Alternativa | Por que foi descartada |
|---|---|
| | |

## Consequências

O que fica mais fácil e o que fica mais difícil por causa desta decisão. Incluir o custo aceito, não só o ganho.

## Revisão

Em que condição esta decisão deve ser reavaliada.
